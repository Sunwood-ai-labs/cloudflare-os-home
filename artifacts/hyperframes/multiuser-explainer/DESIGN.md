# Cloudflare OS Evidence Board

## Style Prompt

An evidence-first technical walkthrough for Cloudflare OS. The viewer should understand the action before reading the UI details: use a calm paper-white canvas, a deep navy evidence rail, Cloudflare orange for the current operation, and mint for confirmed realtime results. Screenshots are treated as primary evidence inside a precise editorial frame, with generous margins and compact metadata.

## Colors

- `#F4F6F8` — paper background
- `#0D1828` — evidence rail and primary text
- `#F6821F` — Cloudflare action accent
- `#2AB78C` — confirmed / realtime result
- `#FFC857` — caution and test state
- `#D7DEE7` — rules, borders, and quiet surfaces

## Typography

- Display: `Bricolage Grotesque`, with `Yu Gothic UI` fallback for Japanese
- Evidence labels: `IBM Plex Mono`, with `Cascadia Mono` fallback
- Use large, high-contrast display type and readable 20px+ explanatory copy.

## Motion

- Medium-energy editorial push between evidence steps.
- Each scene enters with a staggered reveal; the outgoing scene leaves through the same push transition.
- No looping animation. Motion exists to clarify sequence, not decorate the screenshots.

## What NOT to Do

- Do not present raw screenshots without an action label.
- Do not cover the evidence UI with opaque annotation blocks.
- Do not use neon gradients, generic dashboard cards, or tiny web-sized text.
- Do not imply that a UI error was a success; show the Revoke limitation as a warning.
